## 0. 现状一句话

`s1.py` **名义上基于波浪理论，但代码里没有任何波浪划分算法**——没有浪级（degree）识别、没有五浪结构校验、没有斐波那契比例验证。它本质是一个「放量突破 → 次日阴线洗盘 → 盘中上破昨开反包」的**动量 N 字策略**，只是借了波浪的叙事外壳（突破=浪1、洗盘=浪2、反包=浪3）。

## 1. 用三条基本原则审视 s1（回答那三个问题）

制定任何量化策略前必须先想清楚这三条。下面把你的 basic tenets 落到 s1 上。

### 1.1 因子的假阳性

**单因子假阳性**
- s1 的真正"因子"是「突破+洗盘+反包」的 N 字动量形态。它在单一回测区间（如某段趋势市）好看，但：
  - 入口把"任何一天收阴"都当浪2洗盘完成，假阳性极高——大量普通回调被误判为洗盘结束，触发买入。
  - 突破过滤（Z-Score>1.2 + 涨幅>4%）本质是**动量因子**，动量因子高度依赖 regime：趋势市有效、震荡/下跌市崩溃。

**组合假阳性（更隐蔽，s1 的重灾区）**
- s1 的多个过滤器其实是**同一个因子的不同马甲**，并非独立多因子：
  - `MA5>MA10`（趋势）、`Z-Score 量能>1.2`（活跃度）、`涨幅>4%`（动量）、`沪深300>60日线`（市场趋势）——四者都表达"买强势/买动量"，表面分散、实则集中押注单一"动量"因子。
  - 当动量 regime 轮动失效（如 2022-2023 弱震荡），所有过滤器会**一起失效**，而非此消彼长——组合不仅没分散风险，反而放大了动量因子的集中暴露。
- 更糟的是，s1 还混入了与动量**自相矛盾**的拦截：`RSI≥70` 拦截（均值回归思路，会挡掉最肥的浪3主升）和 `空间偏离 25% 上限`（会过早放弃真主升）。两类对立逻辑叠加，既不是干净的多因子，也不是干净的单因子。
- **结论**：s1 的"edge"基本就是被重复确认 4 次的动量因子 + 拍脑袋阈值。必须用**样本外 + walk-forward + 跨时段稳健**验证它是否只是巧合；且加因子前应问"控制动量因子后是否还有增量 alpha"，否则只是换马甲。

### 1.2 逻辑与因子的先后顺序

- 你的主张：**逻辑优先（演绎）**——先有可观察的市场结构/行为偏差，再用因子验证。
- s1 的问题正是**名实颠倒**：它声称的逻辑是"波浪理论（浪1突破、浪2洗盘、浪3主升）"，但代码并没有实现波浪理论，而是先有一个动量启发式（N 字），再把波浪故事**事后贴上去**。这是最危险的反模式：故事自洽，却与代码实际行为不符。
- **逻辑自洽却错误**的陷阱：波浪叙事听起来有理，但实现层面根本无法执行"数浪"；而实现真正在做的"动量"有其**可证伪的弱点**（regime 依赖），s1 却没有针对该弱点的退出规则。
- 正确闭环应是「逻辑给方向 + 失效条件，因子验证逻辑是否成立」。对 s1 来说，可证伪假设应是：**"若这真是浪3启动（经浪级+斐波那契验证），则应延续；若动量 regime 结束/价格跌破浪1起点，则浪级证伪、应离场。"** s1 当前两头都不沾——既不验证浪级，也没有 tied-to-premise 的失效退出。

### 1.3 如何验证有效的策略（灵魂三问）

**(1) 赚谁的钱**
- s1 作为动量/N 字突破策略，利润来自：
  - **行为偏差**：散户追涨（接盘弱势股的人卖在洗盘恐慌低点，策略买回）；
  - **趋势跟随者接力**：突破延续时被趋势资金推高。
- **但对手盘可持续性弱**：在下跌市里的 B 浪反弹中，"浪3"买家恰恰是接盘被套的那批人。s1 无法区分"真浪3"与"B 浪陷阱"，所以这份 edge 在熊市反弹里会反噬。讲不清对手盘可持续性的策略，上线必亏。

**(2) 适用条件**
- s1 仅有 `沪深300>60日线` 这一道粗过滤，**没有浪级条件、没有波动率 regime 条件、没有板块/流动性条件**。其声称的逻辑要求的适用条件，代码几乎全没落地。
- 真实适用条件 = "动量 regime + 上升市"，这正是 s3 的 trend 模式有效区间；但 s1 没有 bear/range 退出（熔断已删，也没 regime 切换），所以会在 2022-2023 类市场**持续 bleed**——与 v2/v4-2 的崩盘同源。

**(3) 失效信号**
- s1 **没有任何 tied-to-premise 的失效信号**。现有离场（`-5%` 硬止损 / `MA20` 趋势止损 / 移动止盈）都是通用规则，不是"波浪证伪"。
- 正确的失效信号应为：
  - **波浪证伪**：价格跌破浪1起点（浪2 不应破浪1起点，破了即浪级失效）→ 立即离场（替代/补充 `-5%` 硬止损）；
  - **动量 regime 失效**：沪深300 跌破 MA60 且 MA60 下行 → 空仓（bear）；
  - **连续 N 次 N 字形态失败** → 暂停（这是原熔断的"精神"，但用统计触发而非固定 5 次，且可选）。
- 失效信号必须**预设并机械执行**，触发即停，宁可错过不在失效中亏。

## 2. 改进项清单（按优先级）

### P0（名实相符 + 去除假阳性，必须先做）
- [ ] **真正实现波浪理论**：加浪级识别（周/月线定大级别推动段 vs 调整段）——这是波浪能成立的前提，s1 当前完全缺失。
- [ ] **五浪结构校验**：突破=浪1 需满足"浪2 回撤不破浪1起点、浪2 缩量、浪3 延长 > 浪1 的 1.618"等规则，否则不认定为浪1。
- [ ] **斐波那契比例替代拍脑袋阈值**：用 0.382/0.618/1.618 替代 Z>1.2、25%、`RSI≥70` 等无依据阈值。
- [ ] **删掉自相矛盾的拦截**：`RSI≥70` 拦截（挡真浪3）与 `25%` 硬上限（弃真主升）改为趋势破位/波浪证伪离场。

- [ ] **拆分"动量同源"**：把 `MA5>MA10`/`Z-Score量`/`>4%`/`沪深300>60MA` 视为同一因子家族，保留 1-2 个代表即可，腾出空间加真正独立因子（波动率、估值、情绪）。

## 3. 重写后的策略路线

### 3.1 第一阶段：s1_v2（纯波浪理论，名实相符）
目标：让 s1 真正按波浪理论运行，而非"动量策略穿波浪外衣"。

1. **底层共用"分形摆动点"**：波浪和缠论都依赖 swing point。s1_v2 直接复用 s3 的「分型→笔→线段」检测作为摆动原语（无需重复造轮子）。
2. **浪级识别（方向层）**：周/月线定大级别处于"推动段"还是"调整段"。只有大级别推动段内的小级别形态才考虑做多。
3. **五浪规则校验（结构层）**：在摆动点上套用 Elliott 规则——
   - 浪2 不破浪1起点；
   - 浪3 不是最短（通常最长，≥浪1 的 1.618）；
   - 浪4 不进浪1价格区间（不重叠，倾斜三角形除外）；
   - 成交量：浪1/3/5 放量，浪2/4 缩量。
4. **斐波那契比例验证（确认层）**：浪3 目标 ≈ 浪1×1.618；回撤位 0.382/0.618 作为洗盘结束的介入参考。
5. **买卖点**：在"浪2 末端 / 浪4 末端"介入（对应回调买点），目标看到浪3/浪5；用"跌破浪1起点"作为证伪止损。

> 这一步解决 1.1/1.2/1.3 的全部问题：逻辑（波浪）真正驱动代码；因子不再同源堆叠；失效信号（破浪1起点 / regime 切换）机制化。

### 3.2 第二阶段：波浪 + 缠论融合
等 s1_v2 跑通后，再做融合——其实二者共享摆动原语，融合成本很低：

- **波浪做"方向层"**：周/月线数浪，定大级别是推动段（只做多）还是调整段（空仓/轻仓）。
- **缠论做"买卖点层"**：在波浪推动段内部，用日/30 分二买、三买精准介入（直接复用 s3_v5 的 `detect_aggressive_buy` + 周线中枢上移过滤），用背驰/结构止损（`stop_ref`）离场。
- **共振区 = 最高胜率**：浪3 末端 / 浪C 末端 ≈ 缠论背驰区，二者共振时是反转胜率最高的区域。
- **分工清晰**：波浪负责"该不该做、做哪个方向"（宏观节奏），缠论负责"具体哪里上车、哪里下车"（微观信号）。波浪补缠论缺的"目标位/浪级"，缠论补波浪缺的"机械化可下单信号"。

### 3.3 与 s3 系列的关系
- s3_v5 已是"缠论定势 + 缠论买卖点"的完整框架，且实测为**熊市防御/择时策略（选股负 alpha，超额全来自避跌）**。
- s1_v2 与融合版定位为**进攻增强**：在趋势市用波浪定势 + 缠论二/三买抓取主升浪，补足 s3 在强牛段"进攻性不足"的短板。
- 二者可共用 `classify_market_regime`：bear 空仓（s3 防御逻辑）、trend 用波浪+缠论进攻（s1 融合逻辑）、range 轻仓。

## 4. 验证与回测计划
1. **s1_v2 单因子/多因子 audit**：先 walk-forward 验证"波浪推动段 + 斐波那契介入"是否真有 alpha，还是又被动量同源掩盖。
2. **分年度超额对照**：像 s3 那样跑 2021–2026 分年，重点看 2022-2023（震荡下跌）是否还 bleed、2025-2026（失效区）表现。
3. **消融实验（A/B）**：
   - A：纯动量 N 字（当前 s1 去熔断版）；
   - B：s1_v2 波浪规则版；
   - C：波浪+缠论融合版。
   单变量对照，确认"加波浪/加缠论"各自贡献多少，避免又陷入组合假阳性。
4. **失效信号回测**：验证"跌破浪1起点止损"和"regime 切换空仓"是否真能截断 bleed。
