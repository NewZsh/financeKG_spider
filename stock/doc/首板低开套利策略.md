# 首板低开套利策略

这是一个独立于现有 `review_common` 的复盘思路文档，用于跟踪“前一日首板，次日低开买入，隔日卖出”的短线套利框架。

## 思路摘要

1. 股票池过滤 ST、科创板、北交所，以及上市未满一年的次新股。
2. 实际入场信号要求同时满足：
   - 前一交易日涨停，且不是连板，按首板处理。
   - 买入日开盘价处于最近 60 个交易日价格区间的下半区。
   - 买入日相对前一日收盘低开 3% 到 4%。
3. 卖出规则按原思路记录为：次日上午盈利则止盈，否则拿到尾盘无条件离场。
4. 为了做日常跟踪，额外保留“今日首板且收盘低于 MA60”的观察池，供次日低开场景使用。

## 新脚本

对应脚本：`python -m stock.review_first_limit_low_open --date 2026-06-03`

输出文件：

1. `data/stock/review_first_limit_low_open_YYYYMMDD.md`
2. `data/stock/review_first_limit_low_open_YYYYMMDD.csv`

Markdown 报告会分成两部分：

1. 指定交易日真实满足“前一日首板 + 当日低开 -3%~-4% + 相对低位”的买点。
2. 当日“首板且收盘低于 MA60”的次日观察池。

## 说明

1. 该脚本目前是日线级复盘工具，不做盘中回测撮合。
2. “首板”按非连续涨停处理，即昨日涨停且前一日不是涨停。
3. “相对低位”采用最近 60 个交易日最高价与最低价的中轴，要求买入日开盘价不高于该中轴。
4. 文中策略仅用于研究，不构成投资建议。
